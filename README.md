# Crown Wellness Club

I created this bilingual wellness-club website to test and develop my web development skills, then pitched it to Crown Gym. Working on it helped me learn to build an animated scrolling banner, pop-up interactions, and a contact experience alongside responsive English and Azerbaijani pages.

[Open the website](https://fsrkh12-arch.github.io/crown-wellness-club/)

## Explore the site

- English and Azerbaijani pages with responsive navigation.
- Venue photography and sections for programs, recovery, and facilities.
- Interactive recovery details, class filters, a daily check-in, and a directions link.

The repository contains the site files in `dist/`, including HTML, CSS, JavaScript, and images. The tour-request form is a frontend demonstration: it shows a confirmation but does not send the request to the club. The page also provides direct phone and email links. It is not connected to a live booking or membership system.

## Run locally

Open `dist/index.html` for English or `dist/az.html` for Azerbaijani in a browser. Alternatively, serve the `dist/` directory with a static web server. No build step is required for the files in this repository.
