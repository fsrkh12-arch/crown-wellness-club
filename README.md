# Crown Wellness Club

A bilingual website for presenting a wellness club's training, recovery, and facilities. The project explores a visual identity and responsive experience across English and Azerbaijani.

[Open the website](https://fsrkh12-arch.github.io/crown-wellness-club/)

## Explore the site

- English and Azerbaijani pages with responsive navigation.
- Venue photography and sections for programs, recovery, and facilities.
- Interactive recovery details, class filters, a daily check-in, and a directions link.

The repository contains the site files in `dist/`, including HTML, CSS, JavaScript, and images. It is a frontend website; the interactive elements should not be assumed to be connected to a live booking or membership system.

## Run locally

Open `dist/index.html` for English or `dist/az.html` for Azerbaijani in a browser. Alternatively, serve the `dist/` directory with a static web server. No build step is required for the files in this repository.
