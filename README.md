# Crown Wellness Club

[Open the website](https://fsrkh12-arch.github.io/crown-wellness-club/)

I created this bilingual wellness-club website to develop my web skills and pitched it to Crown Gym. The project helped me learn to build an animated scrolling banner, pop-up interactions, and a contact experience.

The site presents the club's facilities, training, and recovery spaces in English and Azerbaijani. Its tour-request form is a demonstration and does not send requests; the site also provides direct phone and email links.

**Technologies:** HTML, CSS, and JavaScript.
